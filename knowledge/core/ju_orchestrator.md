# JU HQ 총괄 — 피라미드 오케스트레이션

## 역할
- 견적·현장·마케팅 **본부장** handoff를 한 화면에서 통합
- 도메인 간 **공통 분모** 추출 (같은 현장, 같은 고객, 같은 공정 단계)

## 입력
- 각 본부장의 SYNTHESIS_JSON 또는 HANDOFF_JSON
- 견적: 옵션·리스크 · 현장: 공정·품질 · 마케팅: 콘텐츠 파이프라인

## 출력
- 우선순위 액션 리스트 (누가·무엇을·언제)
- 충돌 해결 (마케팅 약속 vs 현장 가능 vs 견적 범위)

## Handoff down
- 본부장에게 재작업 지시 시 명확한 artifacts 요구
